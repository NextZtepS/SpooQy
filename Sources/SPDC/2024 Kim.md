## Key Results

[[Potassium Titanyl Phosphate (KTP)|KTP]] is used in this experiment at $30$ C for yyz NCPM interaction.

> ([[2024 - Kim - Robust and bright polarization-entangled photon sources exploiting non-critical phase matching without periodic poling.pdf#page=2&selection=7,50,11,1&color=yellow|p.2]])
> The generated Bell states exhibit high brightness, exceeding 25 kHz/mW, and high quality, with the concurrence and the state fidelity values approaching 0.99.

The photon pairs are **denegenerate at $1079.27$ nm** which is in the T-band which a outside of optimal range for fiber optics. ## Key Points

[[NCPM]] crystal offers larger beam window due to their less complicated fabrication compared to [[QPM]] is beneficial for creating (high-dimentional) hyperentanglment [[2024 - Kim - Robust and bright polarization-entangled photon sources exploiting non-critical phase matching without periodic poling.pdf#page=1&selection=130,0,144,16&color=yellow|p.1]].

There exists a $0.36$ nm shift in expected value of signal and idler wavelength obtained experimentally [[2024 - Kim - Robust and bright polarization-entangled photon sources exploiting non-critical phase matching without periodic poling.pdf#page=3&annotation=460R|p.3]].

Second Harmonic Generation (SHG) can be used to run in reverse to check if NCPM can produce nondenegenerate photon pairs [[2024 - Kim - Robust and bright polarization-entangled photon sources exploiting non-critical phase matching without periodic poling.pdf#page=3&selection=355,0,365,13&color=yellow|p.3]].

The coincidence-to-single-photon ratio doesn't scale with pump power from $10$ mW, which shows that the source could be very bright [[2024 - Kim - Robust and bright polarization-entangled photon sources exploiting non-critical phase matching without periodic poling.pdf#page=4&selection=281,0,285,37&color=yellow|p.4]]. **Does this still hold for higher pump value?**
